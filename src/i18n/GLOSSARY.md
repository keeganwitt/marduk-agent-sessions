Tone: plain and direct, like the English. Use the polite/neutral register the platform's own
UI uses (usted-free neutral Spanish with infinitives or "tú" sparingly; "vous" in French;
"Sie" in German; です/ます in Japanese; 합니다/해요 neutral UI style in Korean). Keep button
labels short.

Plurals: use objects with the Intl plural categories the language needs: en/es/pt-BR/fr/de
`one` + `other`; ru `one`, `few`, `many` + `other`; ja/ko/zh-Hans `other` only.
